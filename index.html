01 · Investigation Overview

Security Onion SOC Capstone Project

Project Objective

The project investigates suspicious network activity using Security Onion and associated security monitoring tools. The investigation focuses on alert triage, network traffic analysis and incident classification.

Security Onion Environment

Security Onion was used to collect, index and analyze network security evidence including Suricata IDS alerts, Zeek logs and available PCAP evidence.

Investigation Role

The analyst role was SOC analyst, performing alert triage and incident investigation using Security Onion, Zeek, Suricata and Wireshark.

Suspected Host

The investigation focuses on host 192.168.194.129, associated with repeated database-port scanning alerts.

02 · Key Investigation Findings

Evidence collected from the available Security Onion investigation data.

Suricata

Suricata generated multiple alerts associated with database service ports.

  • MSSQL — TCP 1433
  • Oracle SQL — TCP 1521
  • PostgreSQL — TCP 5432
  • MySQL — TCP 3306

Zeek

Zeek analysis identified the connection to MSSQL port 1433 as suspicious. The investigation identified conn.log as the next pivot for validating repeated connection attempts.

Wireshark

The available five-tuple information confirmed a TCP connection from the suspected host to the internal gateway on MSSQL port 1433.

DNS Activity

A DNS query involving a .cfd TLD was reported. Detailed DNS evidence was not available, therefore the activity requires further review.

06 · Incident Severity

Final assessment based on the available evidence.

MEDIUM

The investigation identified suspicious scanning with possible database targeting. The evidence strength and confidence were assessed as Medium because Zeek, PCAP and endpoint details were incomplete.


The documented scope was a single host, with medium business impact. No successful database access or confirmed compromise was established from the supplied evidence.

07 · Recommended Actions

Recommended remediation and follow-up activities.

HIGH PRIORITY

Investigate the Host

Investigate 192.168.194.129 and confirm the process, user and purpose responsible for the activity.

HIGH PRIORITY

Review Zeek conn.log

Review connection records to validate repeated database connection attempts and the scanning pattern.

HIGH PRIORITY

Restrict Database Ports

Restrict unauthorized access to database ports 1433, 1521, 3306 and 5432.

MEDIUM PRIORITY

Review .cfd DNS Activity

Investigate the reported DNS activity and correlate it with available DNS and endpoint logs.

MEDIUM PRIORITY

Collect Endpoint Logs

Collect endpoint evidence to identify the process and user responsible for the network activity.

LOW PRIORITY

Continue Monitoring

Continue monitoring for recurrence and correlate future activity with Security Onion evidence.

08 · Final Conclusion

Investigation Classification: Suspicious

The available evidence supports suspicious database-port scanning activity associated with 192.168.194.129. Multiple Suricata alerts targeted database ports 1433, 1521, 5432 and 3306.


However, the available Zeek, PCAP and endpoint evidence was incomplete. Therefore, the investigation does not establish a confirmed compromise.


The incident should remain open for further investigation and escalation if additional evidence confirms unauthorized or malicious activity.
