Investigation Case

Incident: Database Port Scanning Investigation

Detection: Suricata via Security Onion

Suspected Host: 192.168.194.129

Target: 192.168.194.1

Initial Alert: ET SCAN suspicious inbound connection to MSSQL port 1433

Classification: Suspicious

Confidence: Medium

Investigation Findings

The investigation correlated available Security Onion, Suricata, Zeek and Wireshark evidence.

Suricata

Multiple alerts identified activity targeting database service ports including MSSQL 1433, Oracle 1521, MySQL 3306 and PostgreSQL 5432.

Zeek

Zeek logs were identified as an important investigation pivot for validating repeated connections and DNS activity. Detailed records were incomplete in the available evidence.

Wireshark

Available five-tuple information confirmed the MSSQL TCP flow associated with the initial Suricata alert.

IOC Analysis

The primary indicator was the suspected host 192.168.194.129, with additional indicators involving database ports and reported .cfd DNS activity.

Network Activity

The documented activity began with a connection to MSSQL port 1433 at 11:58:14 UTC on 21 July 2026.

Additional activity targeted Oracle port 1521, PostgreSQL port 5432 and MySQL port 3306.

A DNS query involving a .cfd TLD was also reported.

Recommended Actions

01 — Investigate Host

Investigate 192.168.194.129 and identify the process, user and purpose responsible for the activity.

02 — Review Zeek

Review Zeek connection and DNS logs to validate repeated connections and investigate DNS activity.

03 — Restrict DB Ports

Restrict unauthorized access to database ports 1433, 1521, 3306 and 5432.

04 — Collect Endpoint Logs

Correlate endpoint evidence with Security Onion, Suricata, Zeek and Wireshark data.

Final Conclusion

The available evidence supports a suspicious classification rather than a confirmed compromise.

The repeated targeting of multiple database service ports indicates possible scanning or probing activity.

The incident remains open because detailed endpoint, Zeek and PCAP evidence was incomplete.

Final Severity: Medium

Confidence Level: Medium
